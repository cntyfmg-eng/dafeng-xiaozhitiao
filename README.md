# 大冯老师的互动小纸条

培训讲座 / 课堂 / 年会现场的**互动小纸条上墙系统**：听众用手机扫码写下感悟，大屏幕实时漂浮展示，营造全场共创氛围。

- 标题：互动小纸条 · 数智化教学大冯老师
- 形态：Windows 免安装小工具（PyInstaller 打包），内含单文件网页版界面
- 本地服务端口：`8765`（局域网内手机扫码直连）

## 功能特性

| 能力 | 说明 |
|------|------|
| 扫码投稿 | 听众手机扫码打开提交页，写完一键「贴上大屏」 |
| 大屏上墙 | 纸条实时漂浮展示，适合培训、讲座、班会互动 |
| 局域网直连 | 电脑开热点或连同一 WiFi 即可，无需外网 |
| 手机直传版 | WiFi 开了「客户端隔离」时改用扫码互传，不依赖局域网 |
| 云端同步（可选） | 支持填入自己的 GitHub Token 把互动数据同步到仓库（令牌仅在本地输入，不写死） |

## 快速开始

1. 到 [Releases](../../releases) 下载 `大冯老师的互动小纸条.rar`。
2. 解压后双击 `大冯老师的互动小纸条.exe` 运行。
3. 大屏页会显示二维码，听众手机扫码即可写纸条上墙。

### 手机连不上？

- 先看程序目录下的《手机连不上看这里》自检说明。
- 常见原因：场地 WiFi 开了 **客户端隔离（AP 隔离）**（校园网/酒店网常见）。解决办法：让**电脑连手机热点**，手机也连同一热点，重新扫码。
- 或在管理员命令提示符放行防火墙端口 8765（TCP/UDP，限本地子网）：
  ```
  netsh advfirewall firewall add rule name="互动小纸条" dir=in action=allow protocol=TCP localport=8765 remoteip=localsubnet
  ```
